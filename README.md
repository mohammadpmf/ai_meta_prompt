# Prompt Reviewers

مجموعه‌ای از چهار قالب فارسی برای بررسی، تکمیل و بازنویسی درخواست‌ها پیش از ارسال به یک مدل هوش مصنوعی.

هر قالب ابتدا ابهام‌ها و اطلاعات ناقص را شناسایی می‌کند، در صورت نیاز سؤال‌های تکمیلی می‌پرسد و سپس دو نسخه از پرامپت نهایی ارائه می‌دهد:

- نسخه عمومی برای ChatGPT، Claude، Gemini، DeepSeek و مدل‌های مشابه
- نسخه مخصوص Codex با درنظرگرفتن دسترسی مستقیم به فایل‌ها و ابزارهای پروژه

## روش استفاده

1. فایل متناسب با موضوع را باز کنید.
2. متن داخل code block را کپی کنید.
3. همه جای‌خالی‌های شماره‌دار `[[...]]` را تکمیل کنید.
4. خط اول راهنما را حذف کنید.
5. متن را برای مدل هوش مصنوعی ارسال کنید.
6. در صورت طرح سؤال تکمیلی، پاسخ‌ها را ارائه دهید.
7. یکی از دو پرامپت نهایی را کپی و در مدل مقصد استفاده کنید.

قالب‌ها پرامپت نهایی را خودکار اجرا نمی‌کنند. برای اجرای آن در همان گفت‌وگو می‌توانید پس از بررسی خروجی بگویید:

```text
خودت همین پرامپت نهایی را اعمال کن
```

## نکات مهم

- اطلاعات حساس، کلیدهای API، رمزها و داده‌های هویتی را پیش از ارسال حذف یا مخفی کنید.
- در استفاده پزشکی، خروجی هوش مصنوعی جایگزین پزشک، داروساز یا خدمات اورژانسی نیست.
- در موضوعات پرخطر مانند برق، گاز و تعمیرات تخصصی، ایمنی و نظر متخصص مقدم است.
- نسخه Codex می‌تواند برای شناخت درخواست فایل‌ها را بخواند، اما تا دریافت فرمان صریح نباید درخواست نهایی را اجرا کند.
